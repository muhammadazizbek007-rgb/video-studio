исчерпывающий список переменных окружения (ENV), необходимых для запуска проекта.

**Что именно искать (просканируй ВЕСЬ репозиторий, кроме `node_modules`):**

1. Все обращения к переменным окружения по всем шаблонам:
   - `import.meta.env.VITE_*` — фронтенд (Vite)
   - `process.env.*` — Firebase Functions (`functions/`)
   - `env.*` в типе `Env` / `interface Env` — Cloudflare Workers (`workers/`)
2. Файлы-подсказки: `.env.example`, `.env*`, `wrangler.toml`, `firebase.json`,
   `.firebaserc`, `functions/package.json`, `workers/package.json`, README и
   `pingtop-content-factory-skill.md`.
3. Fallback-цепочки вида `A || B || C` — это альтернативные имена одной и той же
   переменной, укажи их вместе.

**Формат ответа — три отдельные таблицы, по одной на каждый деплой-таргет:**

### 1. Frontend (Vite, файл `.env` в корне)
### 2. Firebase Functions (`functions/` — секреты через `firebase functions:secrets:set`)
### 3. Cloudflare Worker (`workers/` — секреты через `wrangler secret put`)

Колонки каждой таблицы:

| Переменная | Обязательна? | Что делает | Где используется (файл:строка) | Где взять значение (конкретный URL/страница) | Пример формата |

**Правила заполнения:**

- **Обязательна?** — `ДА` (без неё приложение падает/не стартует), `Опционально`
  (есть fallback или фича просто выключается), `Только для dev`.
- **Где взять** — не общие слова, а конкретика: например
  «Firebase Console → Project Settings → Your apps → Web app → SDK setup and
  config» или «https://replicate.com/account/api-tokens».
- **Пример формата** — маскированный образец (`sk-...`, `r8_...`,
  `{"type":"service_account",...}`), НЕ выдумывай реальные ключи.
- Если переменная относится к платному внешнему API — отметь это и укажи,
  можно ли обойтись без неё (например, есть ли mock-режим).

1. **Минимальный набор для локального запуска** — какие переменные достаточно

   Что при этом не будет работать.
2. **Готовый шаблон `.env`** для корня проекта — со всеми ключами и
   плейсхолдерами, с комментариями.
3. **Готовый список команд** для установки секретов в Worker и в Functions.
4. **Провайдеры генерации** — какие AI-провайдеры видео/изображений
   поддерживаются в коде, какой ключ нужен каждому, и какой из них минимально
   достаточен, чтобы генерация вообще заработала.
5. **Красные флаги** — переменные, которые читаются в коде, но отсутствуют в
   `.env.example`; и наоборот, которые есть в примере, но нигде не используются.

Не сокращай список и не пиши «и другие» — нужны все найденные переменные.
